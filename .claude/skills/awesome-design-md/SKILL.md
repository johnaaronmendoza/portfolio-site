# Awesome DESIGN.md (reference library)

Vendored from https://github.com/VoltAgent/awesome-design-md @ fcc7028 (MIT, see LICENSE). `design-md/<brand>/DESIGN.md` holds one analysis per brand (84 brands, e.g. linear.app, vercel, stripe, figma, apple, raycast, notion…).

How to use:
1. Pick 3–5 brands whose qualities are relevant to the question (e.g. a dense dev-tool brand for UI chrome, an editorial brand for type rhythm, a playful brand for personality) — `ls design-md`.
2. Read their DESIGN.md sections on typography, colour roles, spacing, components and motion.
3. Compare principles, not looks: what makes their system coherent (token discipline, scale ratios, role clarity, restraint) and where the portfolio's system (CLAUDE.md, client/src/index.css) is weaker or stronger.
4. Recommend changes that stay inside CLAUDE.md's binding direction (Paper & Ink, Plex Desktop, neo-brutalist retro web). Never import another brand's identity, logo, palette or signature layout; no impersonation.
